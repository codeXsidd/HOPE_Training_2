# [LeetCode 222] Count Complete Tree Nodes

- **Topic:** Tree Recursion
- **Difficulty:** Easy

## 📌 Problem Statement

Given the root of a complete binary tree, return the number of the nodes in the tree in less than O(n) time.

---

## 💡 Key Algorithmic Idea

- **Core Technique:** Utilizes standard tree recursion patterns.
- **Approach:**
  - Understand the problem constraints and boundary conditions.
  - Implement optimal solution avoiding redundant state or allocations.
  - Maintain clean pointer/state manipulation.

---

- **Space Complexity:** `O(log N)`
