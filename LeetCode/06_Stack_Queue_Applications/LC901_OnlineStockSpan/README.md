# [LeetCode 901] Online Stock Span

- **Topic:** Stack/Queue Applications
- **Difficulty:** Medium
- **LeetCode Link:** [Online Stock Span](https://leetcode.com/problems/online-stock-span/)

---

## 📌 Problem Statement

Design an algorithm that collects daily price quotes for some stock and returns the span of that stock's price for the current day.

---

## 💡 Key Algorithmic Idea

- **Core Technique:** Utilizes standard stack/queue applications patterns.
- **Approach:**
  - Understand the problem constraints and boundary conditions.
  - Implement optimal solution avoiding redundant state or allocations.
  - Maintain clean pointer/state manipulation.

---

## ⏱️ Complexity Analysis

- **Time Complexity:** `O(1) amortized per next call`
- **Space Complexity:** `O(N)`

javac Solution.java
