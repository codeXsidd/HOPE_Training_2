# [LeetCode 622] Design Circular Queue

- **Topic:** Queue & Deque
- **Difficulty:** Medium
- **LeetCode Link:** [Design Circular Queue](https://leetcode.com/problems/design-circular-queue/)

---

## 📌 Problem Statement

Design your implementation of the circular queue supporting enQueue, deQueue, Front, Rear, isEmpty, and isFull.

---

## 💡 Key Algorithmic Idea

- **Core Technique:** Utilizes standard queue & deque patterns.
- **Approach:**
  - Understand the problem constraints and boundary conditions.
  - Implement optimal solution avoiding redundant state or allocations.
  - Maintain clean pointer/state manipulation.

---

## ⏱️ Complexity Analysis

- **Time Complexity:** `O(1) for all operations`
- **Space Complexity:** `O(K)`
