# [LeetCode 2073] Time Needed to Buy Tickets

- **Topic:** Queue & Deque
- **Difficulty:** Easy
- **LeetCode Link:** [Time Needed to Buy Tickets](https://leetcode.com/problems/time-needed-to-buy-tickets/)

## 📌 Problem Statement

There are n people in a line queuing to buy tickets. Return the time taken for the person at position k to finish buying tickets.

---

## 💡 Key Algorithmic Idea

- **Core Technique:** Utilizes standard queue & deque patterns.
- **Approach:**
  - Understand the problem constraints and boundary conditions.
  - Implement optimal solution avoiding redundant state or allocations.
  - Maintain clean pointer/state manipulation.

- **Space Complexity:** `O(1)`
