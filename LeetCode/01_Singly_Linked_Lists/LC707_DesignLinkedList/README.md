# [LeetCode 707] Design Linked List

- **Topic:** Singly Linked Lists
- **Difficulty:** Medium
- **LeetCode Link:** [Design Linked List](https://leetcode.com/problems/design-linked-list/)

---

## 📌 Problem Statement

Design your implementation of the linked list. You can choose to use a singly or doubly linked list.

---

## 💡 Key Algorithmic Idea

- **Core Technique:** Utilizes standard singly linked lists patterns.
- **Approach:**
  - Understand the problem constraints and boundary conditions.
  - Implement optimal solution avoiding redundant state or allocations.
  - Maintain clean pointer/state manipulation.

---

## ⏱️ Complexity Analysis

- **Time Complexity:** `O(1) addAtHead, O(N) get, addAtTail, addAtIndex, deleteAtIndex`
- **Space Complexity:** `O(N)`
