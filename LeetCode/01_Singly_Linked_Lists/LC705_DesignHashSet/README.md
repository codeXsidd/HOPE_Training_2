# [LeetCode 705] Design HashSet

- **Topic:** Singly Linked Lists
- **Difficulty:** Easy
- **LeetCode Link:** [Design HashSet](https://leetcode.com/problems/design-hashset/)

---

## 📌 Problem Statement

Design a HashSet without using any built-in hash table libraries.

---

## 💡 Key Algorithmic Idea

- **Core Technique:** Utilizes standard singly linked lists patterns.
- **Approach:**
  - Understand the problem constraints and boundary conditions.
  - Implement optimal solution avoiding redundant state or allocations.
  - Maintain clean pointer/state manipulation.

---

## ⏱️ Complexity Analysis

- **Time Complexity:** `O(1) average per operation`
- **Space Complexity:** `O(N + K) where K is bucket count`
