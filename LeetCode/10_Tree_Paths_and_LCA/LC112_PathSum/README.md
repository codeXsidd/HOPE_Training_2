# [LeetCode 112] Path Sum

- **Topic:** Tree Paths & LCA
- **Difficulty:** Easy
- **LeetCode Link:** [Path Sum](https://leetcode.com/problems/path-sum/)

---

## 📌 Problem Statement

Given the root of a binary tree and an integer targetSum, return true if the tree has a root-to-leaf path such that summing all the values equals targetSum.

---

## 💡 Key Algorithmic Idea

- **Approach:**
