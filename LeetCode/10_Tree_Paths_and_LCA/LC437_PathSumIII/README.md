# [LeetCode 437] Path Sum III

- **Topic:** Tree Paths & LCA
- **Difficulty:** Medium

## 📌 Problem Statement

Given the root of a binary tree and an integer targetSum, return the number of paths where the sum of the values in the path equals targetSum (path does not need to start/end at root or leaf).

---
