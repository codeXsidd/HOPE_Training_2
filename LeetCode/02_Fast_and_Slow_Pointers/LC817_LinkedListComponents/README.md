# [LeetCode 817] Linked List Components

- **Topic:** Fast & Slow Pointers
- **Difficulty:** Medium
- **LeetCode Link:** [Linked List Components](https://leetcode.com/problems/linked-list-components/)

---

## 📌 Problem Statement

Given the head of a linked list containing unique integer values and an integer array nums that is a subset of the linked list values, return the number of connected components in nums.

---

## 💡 Key Algorithmic Idea

- **Core Technique:** Utilizes standard fast & slow pointers patterns.
- **Approach:**
  - Understand the problem constraints and boundary conditions.
  - Implement optimal solution avoiding redundant state or allocations.
  - Maintain clean pointer/state manipulation.

---

## ⏱️ Complexity Analysis

- **Time Complexity:** `O(N + M)`
- **Space Complexity:** `O(M) where M is nums.length`
