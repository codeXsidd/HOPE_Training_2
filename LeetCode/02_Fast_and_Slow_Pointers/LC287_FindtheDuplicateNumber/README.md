# [LeetCode 287] Find the Duplicate Number

- **Topic:** Fast & Slow Pointers
- **Difficulty:** Medium
- **LeetCode Link:** [Find the Duplicate Number](https://leetcode.com/problems/find-the-duplicate-number/)

---

## 📌 Problem Statement

Given an array of integers nums containing n + 1 integers where each integer is in the range [1, n] inclusive, find the duplicate number without modifying the array and using O(1) extra space.

---

## 💡 Key Algorithmic Idea

- **Core Technique:** Utilizes standard fast & slow pointers patterns.
- **Approach:**
  - Understand the problem constraints and boundary conditions.
  - Implement optimal solution avoiding redundant state or allocations.
  - Maintain clean pointer/state manipulation.

---

## ⏱️ Complexity Analysis

- **Time Complexity:** `O(N)`
- **Space Complexity:** `O(1)`
