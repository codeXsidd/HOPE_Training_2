# [LeetCode 328] Odd Even Linked List

- **Topic:** Reordering & Merging
- **Difficulty:** Medium
- **LeetCode Link:** [Odd Even Linked List](https://leetcode.com/problems/odd-even-linked-list/)

---

## 📌 Problem Statement

Given the head of a singly linked list, group all the nodes with odd indices together followed by the nodes with even indices, and return the reordered list.

---

## 💡 Key Algorithmic Idea

- **Core Technique:** Utilizes standard reordering & merging patterns.
- **Approach:**
  - Understand the problem constraints and boundary conditions.
  - Implement optimal solution avoiding redundant state or allocations.
  - Maintain clean pointer/state manipulation.

- **Space Complexity:** `O(1)`
