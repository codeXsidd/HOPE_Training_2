# [LeetCode 86] Partition List

- **Topic:** Reordering & Merging
- **Difficulty:** Medium
- **LeetCode Link:** [Partition List](https://leetcode.com/problems/partition-list/)

---

## 📌 Problem Statement

Given the head of a linked list and a value x, partition it such that all nodes less than x come before nodes greater than or equal to x while preserving order.

---

## 💡 Key Algorithmic Idea

- **Core Technique:** Utilizes standard reordering & merging patterns.
- **Approach:**
  - Understand the problem constraints and boundary conditions.
  - Implement optimal solution avoiding redundant state or allocations.
  - Maintain clean pointer/state manipulation.

---

## ⏱️ Complexity Analysis

- **Time Complexity:** `O(N)`
- **Space Complexity:** `O(1)`
