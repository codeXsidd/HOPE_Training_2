# [LeetCode 148] Sort List

- **Topic:** Reordering & Merging
- **Difficulty:** Medium
- **LeetCode Link:** [Sort List](https://leetcode.com/problems/sort-list/)

---

## 📌 Problem Statement

Given the head of a linked list, return the list after sorting it in ascending order in O(n log(n)) time and O(1) memory.

---

## 💡 Key Algorithmic Idea

- **Core Technique:** Utilizes standard reordering & merging patterns.
- **Approach:**
  - Understand the problem constraints and boundary conditions.
  - Implement optimal solution avoiding redundant state or allocations.
  - Maintain clean pointer/state manipulation.

---

## ⏱️ Complexity Analysis

- **Time Complexity:** `O(N log N)`
- **Space Complexity:** `O(log N) stack depth`
