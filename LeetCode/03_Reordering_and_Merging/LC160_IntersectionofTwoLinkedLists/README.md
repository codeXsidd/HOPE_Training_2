# [LeetCode 160] Intersection of Two Linked Lists

- **Topic:** Reordering & Merging
- **Difficulty:** Easy
- **LeetCode Link:** [Intersection of Two Linked Lists](https://leetcode.com/problems/intersection-of-two-linked-lists/)

## 📌 Problem Statement

Given the heads of two singly linked-lists headA and headB, return the node at which the two lists intersect. If the two linked lists have no intersection at all, return null.

---

## 💡 Key Algorithmic Idea

- **Core Technique:** Utilizes standard reordering & merging patterns.
- **Approach:**

  - Implement optimal solution avoiding redundant state or allocations.
  - Maintain clean pointer/state manipulation.
