# [LeetCode 24] Swap Nodes in Pairs

- **Topic:** Reordering & Merging
- **Difficulty:** Medium
- **LeetCode Link:** [Swap Nodes in Pairs](https://leetcode.com/problems/swap-nodes-in-pairs/)

---

## 📌 Problem Statement

Given a linked list, swap every two adjacent nodes and return its head. You must solve the problem without modifying the values in the list's nodes.

---

## 💡 Key Algorithmic Idea

- **Core Technique:** Utilizes standard reordering & merging patterns.
- **Approach:**
  - Understand the problem constraints and boundary conditions.
  - Implement optimal solution avoiding redundant state or allocations.
  - Maintain clean pointer/state manipulation.

---

## ⏱️ Complexity Analysis

- **Time Complexity:** `O(N)`
- **Space Complexity:** `O(1)`
